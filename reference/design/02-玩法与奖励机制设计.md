# 玩法与奖励机制设计（讨论记录）

> 2026-09-12 与 ZCode 讨论确定的玩法框架。核心思路：奖励机制分三层——动作爽感（即时）、技能成长（中期）、收集放置（长线）。

## 一、核心动作（先把「抽一支烟」做好玩）

三段式交互，仪式感优先：

1. **点火**：划火柴 / 按打火机（音效 + 屏幕微光）
2. **吸入**：长按屏幕 + `wx.vibrateShort` 震动，烟雾在肺里蓄力
3. **吐雾**：松手，Canvas 粒子从屏幕吐出；烟雾颜色与形态随烟款、技能变化

视觉基调：像素风 UI、霓虹色烟雾、赛博朋克文案（「抽的是数据，伤的是寂寞」）。

## 二、资源系统（一正一负两货币 + 掉落）

| 资源 | 性质 | 说明 |
| --- | --- | --- |
| 尼古丁 | 主货币 | 抽一支 / 吐烟圈产出，用于买技能、解锁烟款皮肤 |
| 焦油 | 负资产 | 攒到阈值触发「咳嗽」负面状态（屏幕抖动、收益减半），需道具清除；给经济引入耗散 |
| 烟蒂 | 掉落物 | 每抽完一支掉落，攒够 N 个合成一次抽奖（抽稀有烟款；**概率需公示**） |

## 三、技能树（按累计抽烟支数解锁里程碑）

技能跟着行为走——做了什么动作，就解锁强化该动作的技能：

| 里程碑 | 技能 | 效果 |
| --- | --- | --- |
| 5 支 | 点烟手法 | 点火动画加速 |
| 20 支 | 烟圈大师 | 吐雾可画圈，圈套圈连击加分 |
| 50 支 | 深吸 | 长按蓄力，单次尼古丁 ×2 |
| 100 支 | 赛博吐纳 | 解锁霓虹烟雾皮肤 |
| 300 支 | 二手烟领域 | 全屏氛围特效 |
| 1000 支 | 电子肺 v2 | 离线收益加成 |

## 四、长线留存

- **放置机制**：点燃的烟「真实地烧」约 10 分钟，退出小程序也在烧，回来收「烟灰」换资源（回访钩子）
- **每日晨烟**：每天第一支双倍 + 连续 streak
- **图鉴**：细支 / 雪茄 / 电子雾化……每款不同粒子特效
- **称号 ladder**：从「新手指间夹烟」到「赛博老烟枪」
- **彩蛋结局**：累计抽太多 → 解锁「赛博戒烟所」剧情线，连续 7 天不抽拿终极称号「清醒者」——反向设计增加深度，也提供「不鼓励吸烟」的叙事自洽

## 五、合规红线（直接影响设计）

1. 个人主体小程序没有「游戏」类目可选（游戏类目需企业主体 + 资质），只能挂工具 / 娱乐类目
2. 「模拟吸烟」题材有被微信审核驳回的现实风险 → 包装成「赛博解压互动玩具」，视觉用抽象雾气 / 能量弱化写实吸烟
3. 不出现真实烟草品牌、不做真实购烟引导；页面挂「纯属虚拟，不提倡吸烟」声明
4. 概率类玩法必须公示概率
5. 做好首次提审被拒后调整文案与视觉的准备

## 六、MVP 范围（第一期）

- 抽烟动作三步曲（点火-吸入-吐雾）
- 尼古丁计数 + 等级称号
- 技能树上表前 5 个（里程碑解锁）
- 图鉴 3 款烟
- 存档用本地 storage；排行榜等社交功能二期上云开发

先验证「动作好不好玩」，再堆经济系统。
